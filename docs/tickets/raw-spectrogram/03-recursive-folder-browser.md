## What to build

用户选择一个文件夹后，应用递归列出所有子文件夹中的采集文件，按需绘制当前项。用户通过文件列表、上一张／下一张和快捷键逐张浏览，切回文件时继续上次的局部观察；空文件和读取失败不会阻断其他文件。

## Acceptance criteria

- [ ] 文件夹选择递归扫描全部子目录，识别 RAW 扩展名的大小写变体，并按相对路径自然排序；相同文件名可通过相对目录区分。
- [ ] 文件列表可收起，显示当前项、文件名和序号；支持点选跳转、上一张、下一张以及左右键，首尾行为明确。
- [ ] 输入控件聚焦时方向键正常编辑，不触发意外切图；列表和切换控件可通过键盘操作。
- [ ] 当前项按需在后台分析，不等待全部文件计算；快速切换后只有目标文件的结果能成为当前图，界面保持响应。
- [ ] 每个文件首次显示全时段，在当前批次内切回已浏览文件时恢复其上次视口；不同文件的视口互不混用。
- [ ] 空目录显示明确状态；空文件、残缺尾块、读取失败在列表或明细中体现，其他文件仍可点选和分析，汇总可区分成功、警告和失败。
- [ ] 单文件入口继续正常工作；此阶段不保留整批完整时频矩阵，为后续相邻预取和有界缓存保留相同的应用级行为约定。
- [ ] 通过已有应用级入口，以多层目录、自然排序名称、大小写扩展名、同名文件、中文路径及异常文件验证完整浏览流程；GUI 冒烟验证列表切换和各文件视口恢复。
