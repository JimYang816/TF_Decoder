## Parent

Part of #1 — [Windows RAW 采集文件批量时频图浏览与 PNG 导出应用](https://github.com/JimYang816/TF_Decoder/issues/1)

## What to build

用户获得 Windows 目录式应用压缩包，解压后双击 EXE，即可离线完成单文件／文件夹导入、交互查看、参数与滤波设置以及单图／批量 PNG 导出。交付包在没有开发环境的目标 Windows 环境中完成验收。

## Acceptance criteria

- [ ] 在 Windows 构建包含 EXE、解释器与依赖的 PyInstaller onedir 应用，提供可分发压缩包；用户无需另行安装 Python、MATLAB 或 MATLAB Runtime，启动与分析均不需要网络。
- [ ] 提供可重复执行的构建方式、简短的解压运行说明及必要第三方许可信息，用户不需要修改开发机配置才能运行。
- [ ] 在未安装上述运行环境的 Windows 验收环境，解压启动后实际导入中文路径下的单个 RAW 与多级文件夹，查看图形并完成参数应用、单图和批量导出。
- [ ] 验证打包后滚轮缩放、平移、框选、恢复全图、前后切图、每文件视口记忆、失败继续、取消和输出保护均能使用。
- [ ] 检查已随各切片完成的中文浅色界面、蓝色操作、可收起侧栏、高级区默认折叠、键盘焦点和非纯颜色状态提示，在 Windows 125%／150% 缩放及较长中文文件名下仍可操作。
- [ ] 运行已有应用级行为测试及少量 GUI 冒烟验收，完整功能不存在分支集成导致的行为倒退；记录交付包版本与验证环境。
- [ ] 最终压缩包与运行说明可供用户直接获取，性能记录基于已测数据，保留首版仅绘图／浏览和 PNG 输出的范围。
