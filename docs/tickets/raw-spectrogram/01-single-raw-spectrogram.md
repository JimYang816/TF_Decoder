## Parent

Part of #1 — [Windows RAW 采集文件批量时频图浏览与 PNG 导出应用](https://github.com/JimYang816/TF_Decoder/issues/1)

## What to build

用户启动中文浅色桌面窗口，通过文件选择器打开一个 RAW 采集文件，看到与原主绘图程序一致的未滤波时频图。该场景打通真实 RAW 读取、信号分析、应用级结果和 Qt 显示，并建立后续功能共用的应用级行为测试入口。技术方向沿用父规格和 ADR 0001。

## Acceptance criteria

- [ ] 用户可选择单个采集文件，界面显示文件名、计算状态、全时段时频图、秒制时间轴、kHz 频率轴和 PSD 强度色条；默认不滤波，计算期间窗口仍可响应。
- [ ] 按每块 32 字节头与 8192 个小端 uint32 样本解析，提取低 24 位有符号计数并按原标定转为电压；不猜测其他 RAW 布局或块头采样率。
- [ ] 默认采样率 96 kHz，严格复现原 1024 点 hanning 窗、512 点重叠、1024 点 FFT、完整窗边界和单边 PSD 标度，输出 513 个频率点。
- [ ] dB 数值、双精度 epsilon 下限、全时段全频率最大值上限和 parula 颜色映射遵守父规格；全零信号能正常显示。
- [ ] 空文件或无完整块时显示可定位原因的失败状态；残缺尾块跳过并警告；读取失败不使应用退出；原采集文件保持只读。
- [ ] 初始界面遵循已确认的中文浅色和蓝色操作方向，输入、图例、状态与键盘焦点清楚可辨，不依赖后续单独的 UI 重做任务。
- [ ] 通过一个应用级入口，以独立确定的有符号边界值、DC、已知频率和幅值信号验证读取、坐标、PSD 与状态；误差容限明确，不只比较截图或复制实现公式。
- [ ] 使用一份现有真实 RAW 完成单文件可视验收，增加文件选择至绘图的 GUI 冒烟验证；不要求运行 MATLAB。
