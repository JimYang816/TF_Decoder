## Parent

Part of #1 — [Windows RAW 采集文件批量时频图浏览与 PNG 导出应用](https://github.com/JimYang816/TF_Decoder/issues/1)

## What to build

用户在已经正确显示的单张时频图中围绕指针缩放、拖动平移、框选放大，并能恢复全图。应用级结果包含明确的当前视口，供后续文件切换和当前视图导出复用。

## Acceptance criteria

- [ ] 滚轮围绕指针位置缩放，默认左键拖动平移；通过有名称和选中状态的工具按钮启用框选放大。
- [ ] 提供恢复全图操作，恢复当前文件全时段与适用频率范围；工具模式切换不会产生不明确的拖动行为。
- [ ] 缩放、平移只改变当前视口，不改变 PSD、文件身份或该文件全时段全频率确定的色阶。
- [ ] 视口使用真实时间和频率坐标，图形缩放后的坐标、单位和色条仍正确；图像按显示分辨率绘制时不改变分析结果含义。
- [ ] 工具可通过键盘访问，焦点清楚可见，按钮提示说明其操作；保持已确认的中文浅色界面。
- [ ] 通过同一个应用级测试入口验证视口变化、恢复全图及分析结果和色阶不变；GUI 冒烟验证滚轮、平移与框选确实连接到这些行为。
