## Parent

Part of #1 — [Windows RAW 采集文件批量时频图浏览与 PNG 导出应用](https://github.com/JimYang816/TF_Decoder/issues/1)

## What to build

用户在界面选择导出当前文件的缩放视图或全时段，并选择输出目录，得到含文件身份、坐标、单位和 PSD 色条的 PNG 图片。该场景复用当前已应用结果与视口，为后续整批导出提供一致的图片行为。

## Acceptance criteria

- [ ] 导出操作明确区分当前缩放视图与当前文件全时段，两种模式在可用图上均可通过界面操作。
- [ ] 当前视图导出忠实体现选定时间和频率区间；全时段导出恢复文件完整时间范围并保留适用的显示频段，不修改用户当前浏览视口。
- [ ] PNG 包含可读的文件身份、时间／频率坐标及单位和 PSD 色条；强度、色阶与当前已应用分析结果一致。
- [ ] 用户可选择输出目录，基本图片名沿用 RAW 文件名；已有同名图片自动加后缀，不覆盖已有文件，不修改采集文件。
- [ ] 导出成功或失败清楚可见；无法写入目录或图尚未就绪时有明确状态，未完成输出不被宣称成功，界面不被长期阻塞。
- [ ] 通过已有应用级入口验证可解码 PNG、范围差异、视口不变、名称和重名保护；GUI 冒烟验证导出模式与目录选择，不依赖跨平台整图像素一致性。
