## Parent

Part of #1 — [Windows RAW 采集文件批量时频图浏览与 PNG 导出应用](https://github.com/JimYang816/TF_Decoder/issues/1)

## What to build

用户为已导入的采集文件批量导出全时段 PNG。应用使用统一的已应用配置和显示频段，顺序完成各文件，保留来源相对目录，并提供进度、取消和成功／警告／失败汇总。

## Acceptance criteria

- [ ] 批量导出按启动任务时的统一参数快照，对每个文件导出完整时间范围及设定显示频段；输出的坐标、PSD 强度、色阶和文件身份与单图导出约定一致。
- [ ] 用户选择输出根目录，图片保留来源相对目录和 RAW 基本名称；同名不覆盖，单文件模式的导出继续正常工作。
- [ ] 顺序分析和导出各文件，不累积整批完整时频矩阵；计算与写入期间界面可响应并显示文件级进度。
- [ ] 文件空、残缺尾块、读取失败或写入失败均有文件级状态；可处理部分按父规格执行，失败后继续其余文件。
- [ ] 取消能停止后续工作，保留已完成图片；未完成项清楚区分于成功和失败，不遗留被当作有效成品的未完成图片。
- [ ] 结束或取消后给出成功、警告、失败和未完成数量及可定位原因的明细，不以重复弹窗打断任务。
- [ ] 通过已有应用级入口验证递归目录输出、同名保护、参数快照、失败继续和取消保留；以确定的任务状态控制取消，不靠任意睡眠。GUI 冒烟验证进度、取消与结果明细。
