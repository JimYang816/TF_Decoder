## What to build

用户在参数栏为当前整批采集文件设置采样率、时频计算参数、真实频段滤波和独立的显示频率范围，点击应用后逐张查看新配置的结果。单文件模式沿用同一套操作。

## Acceptance criteria

- [ ] 常用区域提供滤波开关、通带上下限、显示频率范围和应用操作；采样率、窗长和重叠量等放入默认折叠的高级区域，参数栏可收起。
- [ ] 默认关闭真实滤波，默认采样率和时频参数保持父规格数值；参数编辑后点击应用才生效，当前图可识别其已应用配置。
- [ ] 配置对当前批次统一生效，切换文件继续使用同一配置；没有逐文件隐藏覆盖。
- [ ] 启用滤波时采用原 Chebyshev I 带通规则：通带纹波 0.5 dB、阻带衰减 10 dB、默认过渡带 1 kHz、零初始状态因果滤波。分块保留必要状态和时频重叠，结果与整段处理一致。
- [ ] 仅调整显示频率范围不改变信号分析数值或重新定义色阶；真实滤波与显示裁剪能独立设置。
- [ ] 无效采样率、窗长、重叠量及不合法通阻带或 Nyquist 边界有明确输入错误，不启动错误计算或静默修改处理算法。
- [ ] 后台旧请求不能在新配置生效后覆盖当前结果；切图、修改和应用参数期间界面仍能响应。
- [ ] 通过已有应用级入口验证整批配置、应用前后行为、带内／带外信号、分块连续性、无效配置以及旧结果隔离；GUI 冒烟覆盖参数编辑、应用和高级区域折叠。
