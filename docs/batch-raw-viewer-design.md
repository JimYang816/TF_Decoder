# RAW 时频图应用需求与设计树

本文件记录需求访谈中已确认的内容、代码事实与尚未决定的设计分支。未决项不代表默认需求。

## 已确认的需求

- 交付离线、解压后双击即可使用的 Windows EXE 应用，目标电脑无需另行安装运行环境；不采用 MATLAB。
- 首版只包含时频图绘制与浏览，解码留待后续版本。
- 输入支持选择一个 RAW 采集文件，或选择一个文件夹。
- 选择文件夹时扫描该文件夹及其所有子文件夹中的 RAW 文件。
- 首版只支持现有采集格式，采样率默认 96 kHz，可在高级设置中修改，不自动猜测其他 RAW 格式。
- 以 80ms 主脚本的时频图为基准，默认严格复现 `hanning(1024)` 的窗系数、512 点重叠；时间轴为秒，频率轴为 kHz，绘图参数放入高级设置。
- 提供真正的带通滤波，默认关闭，启用后可设置通带上下限；显示频率范围独立控制。
- 一次显示一张时频图，通过“上一张”“下一张”按钮切换。
- 图中支持局部放大、缩小和平移，交互目标参考 MATLAB 绘图。
- 默认在应用内浏览，按需导出当前图或批量导出全部图，导出目录单独选择。
- 导入完整文件列表后按需计算当前图，后台预取相邻图并缓存；尚未计算的文件允许短暂等待；批量导出时依次处理全部。
- 一次分析按约 100 个 RAW 文件考虑；用户尚未指定未来单文件大小上限，不沿用先前提出的 1000 文件、1 GiB 建议。
- 采样率、时频计算与滤波参数整批统一，点击“应用”后生效；仅调整显示频率范围不重新滤波。
- 色条强度沿用原程序的计算与显示规则，不新增尚未确认的“自动／固定色阶”模式。
- 文件列表按相对路径自然排序，支持点选跳转、“上一张”“下一张”和左右方向键；文本或数值输入期间方向键保留输入行为。
- 图中支持滚轮缩放、左键平移、工具按钮启用框选放大和恢复全图；新文件首次显示全时段，回到已浏览文件时恢复其上次视口。
- 图片输出为 PNG；当前文件可导出当前视图或全时段；批量导出使用各文件全时段与设定显示频段。
- 导出保留来源相对目录，用 RAW 文件名命名；遇到已有同名图片自动增加后缀，不覆盖。
- 空文件标记失败；残缺尾块跳过并提示，仅处理完整块；文件失败后继续其余文件。
- 批量导出提供进度、取消和失败明细，取消后保留已完成图片。
- UI 使用 ui-ux-pro-max 技能辅助设计，目标为交互方便、简洁大气。
- UI 采用中文浅色界面、蓝色主要操作，左右侧栏可收起、中央大图区；顶部导入导出、图上方图形工具、底部进度与文件序号，高级参数默认折叠。

## 设计树

- 首版功能范围：绘图与浏览（已确认）

  - 处理语义

    - 参数整批统一、点击应用生效（已确认）。
    - 色条强度沿用原程序（已确认，PSD 标度与色阶规则已核查）。
  - 批量处理
    - 按需计算、相邻预取与缓存，批量导出顺序处理全部（已确认）。
    - 约 100 文件规模（已确认）；已知数据单文件约 64 MiB，未来上限未知。
    - 相对路径自然排序、异常标记并继续、取消保留已完成输出（已确认）。
  - 交互与输出
    - 滚轮缩放、平移、框选、恢复全图；记忆每文件视口（已确认）。

    - 中文浅色、蓝色操作、双侧栏与中央大图区（已确认）。

    - Windows 离线解压即用，不采用 MATLAB（已确认）。
    - 实现语言与绘图库由代理根据性能和交互需求提出方案，用户未指定语言。
    - 用现有约 64 MiB 样本和约 100 文件批次验证数值、内存与交互；不对未测文件大小承诺耗时。

## 建议的技术方案

采用 Python、PySide6、PyQtGraph 与 NumPy/SciPy。Qt 管理桌面交互，信号读取、滤波和分块 FFT 在后台执行，数值密集操作使用编译内核，时频图矩阵通过图像方式显示；路径列表与有限数量的图形缓存分开管理。这个选择尚未进行本项目性能测试，不据此宣称比 C++ 更快。[NumPy SIMD](https://numpy.org/doc/stable/reference/simd/index.html)、[PyQtGraph ImageItem](https://pyqtgraph.readthedocs.io/en/latest/api_reference/graphicsItems/imageitem.html)、[Qt 线程](https://doc.qt.io/qt-6/threads-qobject.html)

交付采用 Windows 构建的 PyInstaller `onedir` 目录压缩包，用户解压后运行其中的 EXE，解释器和依赖一并分发。相比单文件打包，这与用户明确的“解压点击 EXE”流程匹配，也无需启动时先将全部依赖解压到临时目录。[PyInstaller 部署行为](https://pyinstaller.org/en/stable/operating-mode.html)

技术取舍记录于 [ADR 0001](adr/0001-desktop-qt-vectorized-signal-processing.md)，状态为 proposed，待本次需求访谈的整体方案最终确认。

## 数值一致性与验证计划

- RAW 小端解释、每块头长度、低 24 位符号扩展和原计数转换公式必须与已核查实现一致。
- 严格复现原 `hanning(1024)`：其端点不为零，数学上等价于长度 1026 的对称 Hann 窗去掉两端，不直接使用常见的 1024 点 Hann 默认值。证据为已安装的官方源码 `D:\Software\Matlab\toolbox\signal\signal\hanning.m:3,33,45–59,72`。
- FFT 长度显式为 1024，步长为 512；96 kHz 实信号的一侧输出共 513 个频率点、覆盖 0–48 kHz。保留原程序的分段边界、功率谱密度归一化和 dB 强度含义，不套用其他库的默认去趋势或填充行为。[MATLAB spectrogram](https://www.mathworks.com/help/signal/ref/spectrogram.html)、[SciPy spectrogram 默认参数](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.spectrogram.html)
- 已核查原谱强度规则：先按原公式转为电压，一侧 PSD 采用 `abs(FFT)^2 / (FS * sum(window^2))`，非 DC/Nyquist 频点乘二；图中数值为 `10*log10(abs(PSD) + 2^-52)`。不归一化到文件最大值，不换算为 dBFS。
- 对正常非零录音，原色阶下限为 `10*log10(2^-52)`，约 -156.5356 dB；上限为该文件全时段、全部频率的最大谱强度。主脚本随后才限制纵轴，因此切换显示频段、缩放或平移均不得改变这份色阶。全零信号应提供稳定的退化范围并正常显示。
- 强度依据为已安装官方源码 `D:\Software\Matlab\toolbox\signal\signal\private\pspectrogram.m:181,185,209`、`D:\Software\Matlab\toolbox\signal\signal\computepsd.m:46,56`、`D:\Software\Matlab\toolbox\signal\signal\+signal\+internal\getSpectrogramOptions.m:72–75`、`D:\Software\Matlab\toolbox\shared\signalwavelet\signalwavelet\+signalwavelet\+internal\+convenienceplot\plotTFR.m:105,177–185,214`。此次核查未运行 MATLAB。
- 主脚本没有覆盖 colormap 或色阶；以 MATLAB 标准默认的 `parula(256)` 为原颜色映射参考，不假设脚本之外的个人会话设置。[MATLAB 默认颜色映射](https://www.mathworks.com/help/matlab/ref/colormap.html)、[parula 默认颜色数量](https://www.mathworks.com/help/matlab/ref/parula.html)
- 原滤波器为 Chebyshev I，`cheb1ord` 后调用 `cheby1`，通带纹波 0.5 dB、阻带衰减 10 dB、默认过渡带 1 kHz；采用零初始状态的因果 `filter`，不是前后向零相位滤波。来源为原主脚本 `:73–89`。自定义通带的边界有效性应在执行前校验。
- 用已知频率与幅值的合成信号验证频率位置、PSD 标度、窗系数与符号扩展；用真实样本验证完整读取、滤波与时频显示；用约 100 文件批次验证 UI 响应、缓存有界、预取与导出。
- 实际测量首次显示、缓存切图、缩放响应与峰值内存，再按结果优化；不以尚未进行的测试结果作为性能承诺。
- 在未装 Python、MATLAB 的目标环境验证交付包启动、中文路径和导出；这是交付验收的一部分。
