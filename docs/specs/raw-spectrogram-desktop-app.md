## Problem Statement

信号分析人员已有能够读取单个采集文件（RAW File）、绘制时频图（Spectrogram）并解码的 MATLAB 程序，但每次都要手工复制一个文件路径。面对约 100 个采集文件以及多层文件夹时，逐个操作耗时，也不方便连续比较信号和保存图片。

用户需要一个离线运行的 Windows 桌面应用：既能选择单个采集文件，也能递归导入一个文件夹；一次查看一张可交互的时频图，并保持现有程序的信号计算及功率谱密度（PSD）强度含义。首版专注绘图与浏览。

## Solution

交付一个包含 EXE 及其依赖的压缩包，用户解压后双击 EXE 即可使用，无需安装 Python、MATLAB 或 MATLAB Runtime。

应用提供中文浅色界面、蓝色主要操作、可收起的文件列表与参数栏，以及占主要面积的中央时频图。选择文件夹后递归列出所有 RAW 文件；通过列表、上一张／下一张按钮或快捷键逐张查看。时频图支持滚轮缩放、拖动平移、框选放大和恢复全图，回到已浏览文件时恢复它的视口。

用户可以统一调整采样率、时频计算参数及频段滤波（Band-pass Filtering）参数，点击“应用”后生效。真实频段滤波与显示频率范围（Displayed Frequency Range）独立；默认关闭滤波。时频图的 PSD 标度和色条范围复现已确认的原主绘图程序，不额外增加自动／固定色阶模式。

导入后按需计算当前图、预取相邻图并使用有容量限制的缓存。用户可导出当前缩放视图、当前文件全时段或整批 PNG 图片。异常文件不会中断其他文件，批量导出提供进度、取消和失败明细。

## Implementation Decisions

- 新建 Windows 桌面应用，技术方向为 Python、PySide6、PyQtGraph、NumPy/SciPy，采用在 Windows 上构建的 PyInstaller onedir 包交付。用户已排除 MATLAB 并委托代理选择实现语言；现有 ADR 0001 记录了该方向与 C++/Qt 的取舍，当前仍为 proposed，本规格不擅自改写其状态。
- 当前仓库只有项目规范和设计文档，没有既有应用模块、业务测试入口或打包流程。按职责建立 RAW 读取、信号分析、应用编排、Qt 展示及图片导出与打包能力；以一个应用级公开入口串联主要流程，避免为测试暴露多个内部接口。
- 应用级入口支持导入单文件或递归文件夹、应用参数、请求当前文件分析结果、浏览文件、导出与取消。对外可观察结果包含文件身份、已应用参数、时间和频率坐标、PSD 强度及色阶、进度、警告、失败和导出结果。
- 首版 RAW 契约固定：每个完整块含 32 字节头和 8192 个小端 32 位无符号样本，总长 32800 字节；跳过块头，提取低 24 位，按 24 位有符号整数解释，再除以 2²⁴ 并乘以 8.196 换算为电压。按现有程序处理为一条实数采样序列，不推测其他通道或 IQ 布局，不从未解析的块头猜测采样率。
- 默认采样率 96000 Hz；严格复现原 hanning 的 1024 点窗系数，其数学定义等价于 1026 点对称 Hann 窗去掉两端零值。默认重叠 512 点、FFT 长度 1024、步长 512；一侧结果有 513 个频率点，覆盖 0–48 kHz。分段时间、完整窗边界、末尾处理和原程序一致，不引入库默认去趋势或额外补零。采样率与窗长、重叠量等配置放在高级设置，并进行相互约束校验。
- PSD 为平方 FFT 模除以采样率与窗平方和，实信号一侧谱的非 DC 和非 Nyquist 频点乘二。显示强度取 PSD 加双精度 epsilon 后的十倍常用对数；双精度 epsilon 为 2⁻⁵²。保持 V²/Hz 对应的 dB 数值含义，不转为声压级、dBFS 或相对文件峰值的归一化幅度。
- 对正常非零记录，色阶下限为双精度 epsilon 的十倍常用对数，约 −156.5356 dB；上限取该文件全时段、全部频率上的最大显示强度。视口缩放和显示频率裁剪不重新估计色阶。全零数据使用可正常显示的退化范围。颜色映射参考原脚本未覆盖时的 MATLAB 标准 parula 256 色，不引入个人会话设置或新增固定色阶开关。
- 频段滤波默认关闭。启用后采用与原程序一致的 Chebyshev I 带通设计，通带纹波 0.5 dB、阻带衰减 10 dB、默认过渡带 1 kHz，并采用零初始状态的因果滤波。自定义频带必须形成合法的通带、阻带与 Nyquist 边界，否则明确报错，不静默替换为其他算法。分块处理时保留必要的滤波状态与时频分段重叠，保证结果与整段处理一致。
- 采样率、时频参数与滤波参数对当前批次统一生效，点击“应用”后更新；不提供逐文件隐藏覆盖。计算结果与文件身份和已应用计算参数关联，配置变化后不得显示或导出错误版本的异步结果。显示频率范围与图形视口不改变信号处理结果。
- 导入列表按相对路径自然排序，识别 RAW 扩展名的大小写变体。当前文件按需计算，相邻文件后台预取；前台请求优先，缓存有容量上限，批量导出顺序处理，不保留整批完整时频矩阵。计算、读取和导出不阻塞 Qt 界面线程；图形显示可按屏幕分辨率降采样，但不得改变分析强度、坐标或导出范围的含义。
- 一次只显示一张图。支持列表跳转、前后按钮及方向键；输入控件聚焦时方向键正常编辑。滚轮围绕指针缩放，默认左键平移，框选放大采用显式工具模式，提供恢复全图；每个文件在当前浏览批次内保留自己的视口，首次查看为全时段。
- 当前图导出明确区分当前缩放视图和全时段；批量导出各文件全时段及已设定显示频段。一次导出任务使用同一份已应用参数快照，保证结果一致；PNG 包含足以解释结果的坐标、单位、色条和文件身份信息。
- 输出根目录由用户选择，保留输入的相对目录结构，基本文件名沿用来源 RAW 名称；单文件模式直接输出到所选目录。已有同名图片自动加后缀，原采集文件不被修改。失败后继续其余文件，取消后保留已完成图片，并清楚标识未完成项。
- 空文件或没有可处理完整块的文件标记失败；有完整块但末尾存在残缺块时跳过残缺尾块并显示警告。目录无 RAW、无法读取、无效参数或无法写入输出目录均应给出可定位原因的状态，避免无说明的空白图或重复弹窗。
- UI 使用 ui-ux-pro-max 辅助设计，采用已确认的中文浅色、蓝色主要操作、中央大图区与可收起双侧栏。顶栏放导入和导出，图上方放图形工具，底部显示进度与文件序号；高级参数默认折叠。提供有标签和单位的输入、可见焦点、键盘访问、非纯颜色状态提示和高 DPI 适配。

## Testing Decisions

- 用户已明确确认测试边界：主要通过一个应用级公开入口，覆盖“导入文件／文件夹 → 应用参数并分析 → 浏览结果 → 导出图片”的完整使用流程；GUI 与打包后的 EXE 另做少量冒烟验收。
- 好的测试验证外部可观察行为：文件列表与顺序、分析数值和坐标、已应用配置、状态与错误、视口恢复、生成图片及取消后的输出。不要测试私有函数调用次数、线程类型、内部缓存结构或模块拆分方式，也不要只把实现公式复制成测试期望。
- 主要被测能力包括应用编排及其真实 RAW 读取、信号分析与导出协作；使用临时目录、可复现的合成采集数据和明确的公开结果断言，尽量通过同一个入口覆盖，不增设平行测试接口。
- 数值验证使用独立确定的样本边界值、DC、已知频率与幅值的正弦以及多频信号，检查 24 位符号解释、头部跳过、电压标定、窗定义、频率和时间坐标、单边 PSD 标度与 dB 下限。误差容限按输出数值精度与浮点误差明确约定；不能只断言图“看起来相似”。
- 真实滤波通过带内和带外已知信号验证保留与衰减，以及分块边界的一致性；单独改变显示频率范围不能改变分析结果，缩放和平移不能改变该文件的色阶。
- 文件夹场景覆盖多级目录、大小写 RAW 扩展名、自然排序、同名文件、中文路径、单文件模式以及无 RAW 的目录。缓存命中、淘汰或参数更新后，相同输入与有效配置的外部结果应一致；过期计算不能覆盖新结果。
- 异常场景覆盖空文件、残缺尾块、全零信号、读取失败、参数非法和输出失败；验证警告／失败可定位到文件，其他文件继续处理。取消用确定的任务状态或进度控制，不靠任意睡眠；验证已完成图片保留且未完成项不会被宣称成功。
- PNG 导出验证可解码的文件、必要的坐标与色条信息、当前视图与全时段的范围差异、批量统一参数、相对目录保留和重名不覆盖。避免对整张图片做跨平台逐像素一致性断言。
- GUI 冒烟覆盖导入对话框、按钮与快捷键、输入焦点、滚轮缩放、平移、框选、恢复全图、侧栏与高级区折叠、进度与取消，以及 Windows 125%／150% 显示缩放。少量场景用于证明界面实际连接到已测试的应用行为。
- 用约 100 个文件和现有约 64 MiB 的典型最大样本测量首次显示、已缓存切图、缩放响应和峰值内存，验证界面持续响应、缓存有界且不按总文件数累积完整矩阵。记录机器与参数，不预先承诺尚未测量的耗时或未来文件大小上限。
- 打包验收在未安装 Python、MATLAB 和 MATLAB Runtime 的 Windows 环境中，从压缩包解压后启动 EXE，执行中文路径导入、图形交互及 PNG 导出，验证运行不依赖开发机环境。
- 现有仓库没有产品代码、业务集成测试或可复用的应用级测试先例；技能自身的测试不作为产品测试先例。本功能建立首个应用级行为测试基线，再辅以必要的 GUI 与交付包验收。

## Out of Scope

- 首版解码、协议识别、帧标注及载荷重组；原程序的解码能力留待后续版本接入。
- 自动识别任意 RAW 格式、其他采集设备的二进制布局、多通道或 IQ 解交织。
- 对每个文件分别设置不同的采样率、STFT 或滤波配置。
- 同时显示多张时频图或额外的多图比较界面。
- PDF 等非 PNG 导出，以及用户未确认的全局固定色阶／新强度模式。
- MATLAB 应用实现或要求目标电脑安装 MATLAB、MATLAB Runtime、Python 的交付方式。

- 本规格基于已完成的三轮需求回答、原主绘图程序的只读检查和官方算法源码核查；界面及测试边界已由用户确认。术语遵循本项目领域词汇。
