# 原 MATLAB 数值核对

2026-11-06，在集成分支完成 #5 后，通过同一个 `Application` 公开入口读取真实 RAW 前四个完整块（131200 字节，32768 个采样点），与本机 MATLAB R2024b 的直接结果比较。RAW 仅只读截取作本地验收，未提交采集数据。

验证片段 SHA-256：`27C37916F5753939D9A865A2DC97C3F3CA6D52BA7221EC6BCFA02E809FA4D1EF`。

参考解析逐块跳过 32 字节头，从小端 uint32 提取低 24 位补码，按 `8.196 / 2^24` 转为电压。参考计算直接调用 MATLAB：

```matlab
[~,f,t,p] = spectrogram(x,hanning(1024),512,1024,96000);
[n,wc] = cheb1ord([20000,28000]/48000,[19000,29000]/48000,0.5,10);
[b,a] = cheby1(n,0.5,wc);
y = filter(b,a,x);
[~,ff,tt,pf] = spectrogram(y,hanning(1024),512,1024,96000);
```

| 比较项 | 实测结果 |
| --- | --- |
| 未滤波 PSD 最大绝对误差 | 6.617444900424222e-24 V²/Hz |
| 滤波后 PSD 最大绝对误差 | 1.2511106764864544e-23 V²/Hz |
| 滤波后 dB 最大绝对误差 | 5.5706550483591855e-12 dB |
| MATLAB 滤波原型阶数 | 4 |
| 时间坐标 | 绝对容差 1e-14 秒通过 |
| 频率坐标 | 绝对容差 1e-10 Hz 通过 |

PSD 断言容差：未滤波 `rtol=2e-12, atol=1e-22`；滤波 `rtol=1e-7, atol=1e-20`，以容纳直接型与二阶节实现的浮点差异。软件环境为 Python 3.13.9、NumPy 2.5.4、SciPy 1.18.1。色表由本机 MATLAB `parula(256)` 直接导出，见 README。

这是有限真实片段的数值核对，与应用级合成数据测试互补；不代表所有采集文件已逐项与 MATLAB 比较，也不是性能测量。交付应用不调用 MATLAB，目标电脑无需安装 MATLAB 或 MATLAB Runtime。
