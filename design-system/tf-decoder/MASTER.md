# TF Decoder 界面规范

基于 UI/UX Pro Max 的 Data-Dense Dashboard 风格，针对 PySide6 / Windows 科学分析桌面工具落地。检索结果中的企业营销页结构不适用于本项目，未采用；以下为经过项目适配的设计规则。

## 信息层级

1. 数据源：单行产品名、路径输入、打开文件、打开文件夹、重新扫描。
2. 分析参数：水平排列显示频率、可选带通滤波和应用操作。保留上下限标签，修改后明确提示“应用后生效”。
3. 时频图：占据工作区全宽及剩余高度。文件名、时长、已应用的信号模式与频段集中于标题栏。
4. 图表操作：文件切换、缩放、时间格式、PNG 导出放在图下方的同一行。
5. 状态：底部显示当前批次、成功与失败数量及计算进度。

分析参数可收起；专注视图隐藏数据源和参数栏，保留图表与操作。F11 切换，Esc 返回，保留原有参数栏展开状态。

## 视觉与密度

- 默认窗口最大 1440×900，最小 1060×620；打开时适配屏幕可用区域。
- 外边距 12px，区块间距 8px，内部间距 4/8/12px；无装饰性侧栏、阴影或动画。
- 使用本机微软雅黑，正文 10pt，辅助文字 12px，区块标题 14px，产品名 19px。
- 颜色集中于 `raw_browser/theme.py`：背景 #F1F5F9，面板 #FFFFFF，正文 #172B43，辅助文字 #526278，主操作 #1E40AF，面板边框 #CBD5E1，控件边框 #8191A6。使用明确的浅色 Qt 调色板，避免 Windows 深色主题影响原生控件。
- 交互图不再重复文件标题；使用随画布尺寸变化的固定物理边距和窄色条。导出图仍有独立标题。
- 科学数据色图仍为原始 parula，不改变频谱数值、色阶或滤波方法。

## 交互与可访问性

- 原生按钮和输入控件，保留可见焦点、禁用状态、可访问名称、字段标签。
- 长文件名中间省略，完整路径保留在提示中，完整文件名提供给辅助技术。
- 参数未应用时显示文字提示，当前图标题只描述已应用的参数。
- 编辑输入框时左右键用于光标移动；其他位置保留左右文件切换。
- Ctrl+O 打开文件，Ctrl+Shift+O 打开文件夹，Ctrl+Return 应用参数。
- 初始、空目录、计算中及失败状态提供文字说明，不能伪造示例为用户数据。

## 验证

`python -m unittest discover -s tests -v` 验证真实 RAW 管线、布局边界、专注视图、键盘操作、参数应用、滤波、缩放、时间格式与独立 PNG 导出。

`python tests/test_workspace.py --screenshots` 生成三种布局及空状态的预览。截图使用确定性的合成信号，仅供界面检查。
