# TF Decoder 桌面 UI 规范

本规范落实已确认的中文浅色、蓝色主要操作、中央单图与可收起侧栏方向。使用 ui-ux-pro-max 的桌面分析工具建议，按本应用裁剪；不采用查询中与本产品不符的营销布局或多图卡片。

## 布局与信息层级

- 顶栏：应用名称、打开 RAW 文件、打开文件夹、导出菜单。
- 左栏：当前批次文件列表，约 240 px，可收起；文件名为主、相对目录为辅；当前项明显高亮，异常项同时显示图标与文字。
- 中央：文件标题与图形工具栏；时频图占主要空间，时间轴、频率轴及原程序强度色条齐全；底部放上一张、文件序号、下一张。
- 右栏：约 280 px，可收起；常用滤波开关与通带、显示频段、应用参数直接可见；采样率与 STFT 参数放进默认折叠的高级区域。
- 底部状态区：当前计算或导出进度、取消操作和失败明细入口。不用连续弹窗打断文件浏览。
- 窗口缩小时优先收起侧栏，中央图仍可操作；尊重 Windows 显示缩放，标签不因高 DPI 丢失。

## 视觉基础

| 用途 | 建议值 |
| --- | --- |
| 应用背景 | `#F5F7FA` |
| 面板与图区外框 | `#FFFFFF` |
| 主文字 | `#172033` |
| 次要文字 | `#526174` |
| 边框与分隔 | `#D6DEE8` |
| 主要操作 | `#2563EB`，文字 `#FFFFFF` |
| 当前文件背景 | `#EFF6FF`，文字 `#1E40AF` |
| 失败提示 | `#B91C1C`，同时提供文字原因 |
| 警告提示 | `#92400E`，同时提供警告文字 |

使用 Windows 系统中文字体（优先 Microsoft YaHei UI），正文约 14 px，辅助文字不小于 12 px；数值优先使用对齐的数字。采用 4/8 px 间距体系、6–8 px 小圆角、清晰分隔，避免重阴影与装饰性动效。以上视觉值是实现起点，交付前需实测文字对比度、焦点状态和显示缩放。

时频数据自身的颜色映射和强度范围以原程序规则为准，界面主题色不改变时频图数据语义。

## 交互

- 滚轮以指针位置为中心缩放；默认左键拖动平移；框选放大通过显式工具模式启用。
- 保留恢复全图按钮；新文件显示全时段，已浏览文件恢复自己的视口。
- 左右方向键切换文件，但输入控件聚焦时不抢占其方向键。
- 参数编辑与应用分开；显示当前已应用配置，避免旧图被误认为使用了新参数。
- 导出当前图时明确选择当前视图或全时段；批量导出按同一份已应用参数生成。
- 计算与导出显示进度；可取消；空文件、残缺尾块及失败原因可在列表或明细中查看。

## 可用性检查

- 键盘可访问导入、文件列表、参数、图形工具和导出，焦点清楚可见。
- 所有输入都有标签、单位与明确的边界错误信息；图标按钮有名称与状态说明。
- 正常文字对比度目标至少 4.5:1；不能只依靠颜色表示失败、警告或当前项。
- 图形工具和文件切换不发生布局跳动，耗时计算不阻塞界面线程。
- 在无文件、计算中、失败、成功、导出中和取消后均提供明确状态。
- 检查中文长路径、同名文件、不同窗口尺寸和 Windows 125%/150% 缩放。
