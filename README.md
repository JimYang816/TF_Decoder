# TF Decoder

**[下载最新版（Windows x64）](https://github.com/JimYang816/TF_Decoder/releases/latest)** · 在发布页的 **Assets** 中下载 `.exe`，双击即可运行。

中文 Windows 桌面工具。每次查看一个 RAW 的时频图，以10个文件为一批在后台预计算，支持左右切换、频段调整、可选带通滤波和 PNG 导出。

## 双击 EXE 使用

在 Windows x64 上，双击项目根目录里的 **`TF Decoder.exe`** 打开主窗口，再选择 RAW 文件或数据目录。可以单独复制这个 EXE 到另一台电脑使用，无需安装 Python 或 MATLAB。RAW 数据文件需另行准备。程序启动时会自动解包运行依赖，窗口出现前可能需要几秒。

## 从源码启动

在项目根目录用所选 Python 环境运行以下命令。

```powershell
python -m pip install -r requirements.txt
python main.py
```

可以在启动时指定 RAW 文件或数据目录，例如 `python main.py ".\数据"`。

## 重新打包 EXE

在 Windows x64 上，使用 64 位 Python 3.13，在项目根目录运行以下 PowerShell 命令。打包完成后，`TF Decoder.exe` 会直接生成在项目根目录。

```powershell
python -m venv .build-venv
.\.build-venv\Scripts\python.exe -m pip install -r requirements-exe.txt
.\.build-venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --distpath . "TF Decoder.spec"
```

## 使用

1. 点击“打开 RAW…”绘制单个文件，或点击“打开文件夹…”加载所选文件夹及其所有子文件夹中的 RAW 文件。两个按钮分别打开 Windows 原生文件和文件夹选择窗口。也可以在主窗口输入文件或目录路径并按回车，程序会自动识别路径类型。RAW 扩展名不区分大小写，扫描结果按相对路径自然排序，例如 `file2.raw` 在 `file10.raw` 之前。
   程序会记住上次使用的文件夹，重启后再次选择文件或文件夹时会从该位置开始。
2. 点击“上一文件 / 下一文件”，或按键盘左右箭头。编辑路径和参数时，左右键用于移动输入光标。主图显示一个文件，每批最多10个，先计算当前文件，再后台准备其余文件。第10个的下一个是第11个；第11个的上一个回到第10个。首尾不循环。
3. 默认显示整个文件的0–48 kHz。修改“显示频率”后点击“应用设置”。显示频率只能在0–48 kHz内，并至少包含一个FFT频率点。仅修改显示频段会复用已计算的频谱。
4. 按住左键拖动会出现矩形选框，松开后放大所选区域。中键拖动平移，左键双击恢复全图。滚轮可围绕鼠标位置缩放，`Shift+滚轮`只缩放时间轴，`Ctrl+滚轮`只缩放频率轴。也可点击“放大 / 缩小 / 恢复全图”按钮。缩放与平移限制在当前文件和显示频段内，放大使用完整时频数据，无需重新计算。保存当前图会保留放大、平移后的视图。
5. 如需滤波，勾选“带通滤波”，设置上下限，再点击“应用设置”。默认通带20–28 kHz，要求 `0 < 下限 < 上限 < 48 kHz`。主图切换为滤波后的时频图；取消勾选并应用即可恢复原始信号。滤波上下限与显示上下限相互独立，滤波变更会重新计算当前批。
6. “保存当前图”选择输出目录，保存当前频段和缩放视图；“保存本批”在本批准备完成后可用，每个有效文件各输出一张完整时间范围的PNG，使用点击保存时的频段和滤波状态。文件名为 `原文件名_stft.png`；重名自动加 `_2`、`_3` 等后缀。保存完成显示成功、失败数量及失败原因。

坏文件会在其位置显示失败原因，不阻断本批的其他文件。可继续用箭头浏览，批量保存时将其计为失败。关闭窗口会取消后台计算和后续导出；正在执行的滤波或单张图片写入会完成后退出。

### 界面与快捷键

时频图横向铺满工作区，参数集中在顶部。点击“分析参数”收起或展开参数栏，点击“专注视图”收起数据源和参数栏，获得更大的绘图区域。再次点击或按 Esc 返回。参数修改后会提示“应用后生效”，图表标题栏始终显示已经应用的频段和滤波状态。完整文件路径可通过文件名提示查看。

| 快捷键 | 操作 |
|---|---|
| Ctrl+O | 打开 RAW 文件 |
| Ctrl+Shift+O | 打开文件夹 |
| Ctrl+Return | 应用参数 |
| ← / → | 上一文件 / 下一文件（输入框中用于编辑） |
| F11 | 切换专注视图 |
| Esc | 退出专注视图 |

## 支持的 RAW 格式

工具按以下固定格式解析 RAW 文件：

| 项目 | 约定 |
|---|---|
| 采样率 / 通道 | 96000 Hz，单通道 |
| 每个数据块 | 32字节块头 + 8192个四字节采样，共32800字节 |
| 字节顺序 | 小端 uint32 存储 |
| 有效采样值 | 低24位；按第24位还原有符号数，高8位忽略 |
| 文件完整性 | 文件非空，长度必须是32800字节的整数倍 |

原脚本能尝试读取部分尾块；本工具按已确认的完整块要求，对不完整尾块报格式错误。其他设备导出的连续 `int32`、不同块头或采样率，需要调整读取规则后才能使用。

## 计算与显示约定

- PSD绘图采用 `decode_6_12k_80ms_M0.m` 中未滤波 `spectrogram` 的规则。按该脚本将采样计数换算为电压：`x_volts = x_counts / 2^24 * (4.098 * 2)`，保留实际幅值和直流分量。
- 使用 MATLAB `hanning(1024)` 对应的窗口，即 `hann(1026, sym=True)[1:-1]`；窗长1024、重叠512、FFT点数1024。这些参数固定，无高级设置。
- 只计算完整帧，不补边、不补尾、不逐帧去趋势。频率间隔93.75 Hz，帧间隔约5.333 ms。
- 功率谱密度先计算 `P = |S|^2 / (96000 * sum(window^2))`，单边谱的内部频率点乘2，DC和Nyquist点保持原值；色标为 `10*log10(P + eps64)`，单位 `dB/Hz`，对应电压功率谱密度（V²/Hz）。色条标签为“功率/频率(dB/Hz)”。
- 按 MATLAB 默认绘图设置，下限为 `10*log10(eps64)`，约 −156.5356 dB/Hz，上限为整文件全部频率点的最大PSD dB值；改变显示频段或缩放只改变视野。全零信号使用与 MATLAB 一致的有效回退色阶。不同文件数值采用相同电压标定，各图色条上限自动变化，比较强弱时应读取对应的dB/Hz数值。
- 使用从本机 MATLAB 提取的原始 `parula(256)` 色表，低值为紫蓝色，依次过渡到蓝、青、绿，高值为黄色；界面与PNG导出采用相同色图、PSD计算和色阶。
- 工具可选滤波采用512阶Hamming窗FIR。长信号使用双向滤波，反射长度1536；采样点数不超过1539时采用单向滤波，输出保留电压幅值。该可选滤波器与解码脚本 `if_filter=1` 时的Chebyshev滤波器不同；未滤波路径按解码脚本数值对照，可选滤波路径按相同FIR条件对照。
- 计算使用float64，以2048帧为一块进行FFT，并使用最多4个工作线程。内部读取的信号在原数组上换算电压，减少大数组复制。计算频谱时记录整文件的峰值，作为各显示频段的统一色阶上限。当前批最多10个文件的float32频谱按块写入系统临时目录，浏览和导出时按需读取。一个175秒文件约需64 MiB临时空间，10个同等长度的文件约需640 MiB。切换批次或关闭程序后会释放用完的缓存，导出中的数据保留至导出结束。
- 交互绘图只渲染当前视野，并按窗口像素数选择时间采样密度；全景取原始网格点显示，保持原来的dB值和色彩对比度，放大后逐步恢复完整网格。比屏幕像素更窄的细节需要放大查看，原始频谱缓存不变。连续滚轮、拖动会合并重绘请求，并复用标题、色条和背景，缩放时更新图像与坐标刻度；目标上限约60帧/秒，实际帧率取决于电脑和窗口尺寸。PNG按导出DPI重新完整绘制，不复用屏幕截图。
