TF Decoder 0.1.0 · Windows x64 便携版

1. 将整个 ZIP 解压到可写目录（支持中文路径）。不要直接在压缩软件中运行。
2. 打开 TF-Decoder 文件夹，双击 TF-Decoder.exe。请保留旁边的 _internal 文件夹。
3. 点“打开 RAW 文件”或“打开文件夹”（包含子目录）。应用仅只读采集文件。
4. 滚轮缩放、左键平移；“框选放大”选中区域，“恢复全图”恢复范围。
   上一张／下一张或左右键切图，输入框中的方向键仍用于编辑。
5. 右栏修改参数后点“应用到整批”；显示频段与真实带通滤波互相独立。
6. “导出 PNG”选择当前视图、全时段或整批，再选输出目录。
   保留相对目录；同名图片自动加后缀；批量取消保留已完成图片。

无需安装 Python、MATLAB 或 MATLAB Runtime；启动、分析和导出不需要联网。
支持当前受 Microsoft 支持的 Windows 10/11 x64；本版本实际验证环境见
BUILD-INFO.json 和仓库 docs/portable-delivery.md。干净 Windows 机器验收另行记录。
首次版仅时频绘图／浏览与 PNG 导出，不包含解码。默认采样率为 96 kHz。
RAW 格式固定为 32 字节头＋8192 个小端 uint32，取低 24 位有符号样本。
空文件显示失败，残缺尾块显示警告并使用完整块；失败文件不阻断其他文件。

如启动失败，请保留完整错误文字、Windows 版本与 BUILD-INFO.json。
不要只复制 EXE 或删除依赖文件。请将整个文件夹和许可说明一起分发。
THIRD-PARTY-NOTICES.txt 与 licenses 目录列出第三方组件及许可原文。
软件没有数字签名。首次运行可能显示 Windows 来源提示；请核对发布方提供的
ZIP SHA256 后按照所在单位的软件使用规则操作。
